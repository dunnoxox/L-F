# ROZSZERZENIA (do odhaczenia: biorę / nie biorę / później)
Format: DODATEK DO / CO DOKŁADA / PO CO / CO ZMIENIA / STATUS. Rekomendowana kolejność: 1,2,3,4,5,6,7,8.

## ZAMÓWIONE
**Z1. Porządek w magazynie.** DODATEK DO: sterta w skrzyni (demo v1, game.js). CO DOKŁADA: rzeczy w skrzyniach per linia tramwaju + jedna sterta "nieprzetworzone". PO CO: gracz wie GDZIE szukać. ZMIENIA: sposób szukania (nie czucie przeciągania). Wariant A: 3 skrzynie wg linii + sterta. Wariant B: półki wg kategorii (portfele, torby, ubrania) + sterta z dostawy. Rekomenduję A (pasuje do dostaw tramwajem). STATUS: zamówione, wariant do wyboru.
**Z2. System dźwięku nocy.** DODATEK DO: audio/okienko_projekt_dzwieku.md i prototyp. CO DOKŁADA: mikser, stany okienka, lampa/burza jako zdarzenia, loudness, checklista WebGL. ZMIENIA: nic w mechanice. STATUS: zamówione; projekt już w ~70% (szyny, filtr okienka).

## OPCJE
3. **Model prawdy (jawne/prywatne/kontekst).** DODATEK DO: wnętrza rzeczy + sekrety w rozmowach. W Okienku już jest (sekrety odblokowują pytania). Zmienia: nic. Rekomenduję: biorę.
4. **Typologia petentów w danych** (WLA, ZGA, POD...). DODATEK DO: JSON gości. Pole `typ`. Zmienia: nic. Biorę.
5. **Drabina dowodów.** DODATEK DO: decyzja wydaj/odmów. Zmienia: dodaje waga dowodu w ekranie decyzji. Później.
6. **Wyciek informacji.** DODATEK DO: pytania. Zmienia sposób zadawania (pytania naprowadzające). Wymaga zgody; rekomenduję później.
7. **Rejestr/księga wydań z kodami półek, sejf, retencja.** DODATEK DO: księga wydań (już w fabule, wyrwana strona). Zmienia: nowy ekran. Później (E2).
8. **Ulepszanie biura.** DODATEK DO: sobotnie rozliczenie (czynsz). Zmienia: ekonomia. Rekomenduję E2, lista: lampa, okno, radio, szafka, drzwi.
9. **Konsekwencje między dniami, wielu zgłaszających, nagroda znalazcy, łapówki.** DODATEK DO: echo wieczorne, wątek Skrytka. Już częściowo jest. Biorę.
10. **Seed + link wyzwania.** DODATEK DO: tryb boczny "losowa noc". Zmienia: dodaje tryb. Później.
